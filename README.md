# Earley Air Control, Inc. Website Concept

Standalone Next.js website concept for outreach.

## Run locally

```bash
pnpm install
pnpm dev
```

Original website: https://earleyaircontrol.com/

The source site exposed a tiny icon rather than a usable full logo; this concept uses a labeled text wordmark and the company service van photo. The request form is a preview and does not send submissions. Service-area maps use OpenStreetMap and need internet access. Confirm details before publishing.
